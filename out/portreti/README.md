# Portreti

Gumbi za preklop jezika namesto zastav prikazujejo matematika, ki ga povezujemo
z danim jezikom:

Vse tri so na Wikimedia Commons označene kot **javna last** (public domain).
Navedba vira zato ni pravna zahteva, je pa lepa navada.

Datoteke so pomanjšane različice (širina 250 px), kot jih postreže Commons.
Portret ni jezik, zato ime jezika ostaja v atributih `title` in `aria-label` ter
v skritem besedilu - glej `predloge/jezik_povezava.html`.
